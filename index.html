Sater Cryptograph

PythonPyQt6MySQL

An interactive cybersecurity toolkit for learning and experimenting with classical cryptographic algorithms through encryption, decryption, file integration, and activity logging.

Purpose: Implement classical ciphers from first principles and make them explorable, so the maths behind each algorithm is something you can actually play with.

  • Implements Caesar, Affine, Rail Fence, Columnar Transposition, Vigenère, and ROT13 ciphers
  • Cryptographic logic kept in its own src/ layer, separate from the interface
  • MVC-style separation across gui/, src/, and controllers/ for presentation, algorithms, and data access
  • MySQL activity log recording every encryption and decryption operation
  • File I/O for loading plaintext from files and saving encrypted results
  • Custom PyQt6 interface styled with QSS, featuring animated transitions and glassmorphism

Demonstrates: algorithm implementation, modular code structure, database logging, custom UI development
